# Report blueprint

## Dashboard story arc

1. Executive overview: what is the current tourism landscape?
2. Destination explorer: which places are worth investigating?
3. Budget intelligence: how do cost and value compare?
4. Season & climate: when should travelers go?
5. Tourism insights: which categories and states are driving interest?
6. Recommendation explorer: who should visit what and why?
7. Data quality dashboard: how reliable is the analytic foundation?

## Layout principles

- Minimal, executive, dark theme.
- Consistent spacing and rounded cards.
- Use a restrained palette with high-contrast accents for emphasis.
- Every visual should answer a business question.
- Maintain one primary story per page.

## Navigation structure

- Left side vertical navigation with page icons.
- Page buttons positioned in a compact, modern header.
- Use bookmarks for state, budget, and season-focused views.

## Tooltips and drill-throughs

- Tooltips should show rating, budget, duration, and trend context.
- Enable drill-through from the destination explorer to a detail page for a selected attraction.
- Use bookmarks for executive summary, budget spotlight, and seasonal planning views.

## Filters and slicers

- Report-level filters: State, Budget Category, Popularity Tier, Travel Complexity.
- Page-level slicers: Season, Attraction Type, Traveler Profile.
- Sync slicers across overview, explorer, and recommendation pages.

## KPI definitions

- Total Attractions
- Total Cities
- Total States
- Average Rating
- Average Daily Cost
- Average Visit Duration
- Popularity Index
- Budget Friendly %
- Season Ready Count

## Design notes

- Use a dark canvas with light text and accent colors for cards.
- Add subtle separators and shadowing to create a premium feel.
- Default page background should be deep navy with soft gray panel surfaces.
- Keep labels concise and executive-friendly.
