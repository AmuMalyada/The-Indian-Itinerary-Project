# Dashboards

This folder is where exported dashboard files (Power BI `.pbix`, Tableau
`.twbx`) live once built — they're binary/tool-specific so they aren't
generated by the Python pipeline. Build guidance lives in
[`../powerbi/POWERBI_GUIDE.md`](../powerbi/POWERBI_GUIDE.md).

## Recommended dashboard pages
1. **Overview** — national KPIs + state choropleth
2. **Budget Analysis** — fee distribution, cost by popularity tier
3. **Season & Climate** — monsoon/summer/winter suitability by state
4. **Destination Popularity** — treemap, top-N tables
5. **Trip Planning** — interactive filtered explorer

## Data sources for dashboards
- `final_dataset/attractions_flat_powerbi.csv` — primary, denormalized
- `final_dataset/indian_itinerary.db` — normalized, for tools that support
  relationships/star schemas natively (Power BI, Tableau via ODBC)
